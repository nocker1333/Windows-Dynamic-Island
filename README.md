# 🏝️ Windows Dynamic Island

Реализация знаменитого Dynamic Island от Apple для операционной системы Windows. Написано на PowerShell с использованием WPF (Windows Presentation Foundation).

## ✨ Возможности
- 🎵 **Медиа-плеер**: Управление музыкой (Spotify, YouTube Music и др.) через WinRT API.
- 📋 **Буфер обмена**: История копирования с возможностью быстрого доступа.
- 🔔 **Уведомления**: Отображение системных уведомлений прямо в "острове".
- 🌙 **Не беспокоить**: Режим тишины с таймерами (15 мин, 1 час, до утра).
- 📷 **Скриншоты**: Быстрое создание скриншотов через дополнительный мини-островок.
- 📊 **Статистика**: Отображение заряда батареи, CPU и RAM.
- 🔄 **Адаптивность**: Автоматическое перемещение острова влево или вверх в зависимости от активного окна.

## 🚀 Как запустить
1. Убедитесь, что у вас установлен **Windows PowerShell 5.1** или новее.
2. Скачайте файл `DynamicIsland.ps1` и `run.bat`
3. поместите оба файла в одну папку
4.запустите `run.bat`


🛠️ Требования
Windows 10 / 11
.NET Framework 4.7+

⚠️ Важно: Для работы уведомлений вам может потребоваться вручную разрешить доступ в настройках Windows: Параметры -> Система -> Уведомления -> Разрешить приложениям доступ к уведомлениям.
